# Banking Management System

1.Project Description

The Banking Management System is an SQL-based project developed to manage banking information efficiently. It stores and manages customer details, bank accounts, deposits, withdrawals, and transaction records.

2. Features

* Manage customer information
* Create and manage bank accounts
* Check account balances
* Record deposits and withdrawals
* Manage banking transactions
* Use SQL queries to insert, update, delete, and retrieve data
* Use primary keys and foreign keys to maintain data relationships

3. Technologies Used

* MySQL
* SQL

4. Database Tables

* Customers
* Accounts
* Transactions

5. SQL Concepts Used

* CREATE DATABASE
* CREATE TABLE
* INSERT
* UPDATE
* DELETE
* SELECT
* WHERE
* GROUP BY
* ORDER BY
* JOIN
* Primary Key
* Foreign Key
* Constraints

6. How to Run

1. Open MySQL Workbench or MySQL Command Line.
2. Create the database.
3. Run the SQL table creation queries.
4. Insert the required data.
5. Execute the queries to manage and view banking information.

__ Purpose__

This project demonstrates practical knowledge of SQL database management and provides a simple system for managing banking operations and customer account information.
